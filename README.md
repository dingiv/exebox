# exebox

> wine/proton 的前端 —— 快速方便地在 Linux 上玩转 exe 程序,把 Windows 软件迁移到 Linux 平台。
> 易用性与专业性/灵活性/底层能力暴露,我们选择尽可能都要。

一个程序 = 一个"箱"(manifest + prefix + 日志),声明式清单(类 docker-compose),
CLI 优先,清单之外零隐藏参数。
